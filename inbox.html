Start receiving boosts

You don't have a nutzap profile yet. This creates a receiving key, saves it encrypted to you on Nostr (a NIP-60 wallet event, which only your signer can decrypt), and publishes which mints you accept (NIP-61). Any NIP-60 wallet can use the same key later.

Only list mints you trust. A mint holds the sats behind the ecash until you collect it. To try things out first, add the test mint https://testnut.cashu.space (fake sats).
